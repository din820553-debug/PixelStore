# PixelStore

Магазин рангов и цифровых товаров Hypixel: адаптивная витрина, корзина, просмотр товаров и MVP++-подтверждение. Добавлены история заказов, кабинет продавца и серверное хранение документов.

## Быстрый запуск

Для витрины: откройте `index.html` через статический сервер. Без настроенного API создаются только локальные демозаказы — продавцу они не отправляются.

Для сервера нужен Node.js 24+; внешних зависимостей нет:

```sh
npm test
npm start
```

Витрина: http://localhost:3000. Кабинет продавца: http://localhost:3000/admin. Для входа задайте `ADMIN_TOKEN` через окружение; ключ должен быть случайным и не короче 32 символов. Параметры описаны в `.env.example`; этот пример не загружается автоматически.

## Хранение

Сервер использует SQLite на постоянном диске. Заказы содержат снимки состава и рублёвых цен. Файлы PDF/JPEG/PNG/WebP хранятся приватно в базе. Покупателю можно явно разрешить скачивание конкретного документа по ключу его заказа. Кабинет включает ручной учёт оплаты и выполнения, расходы, журнал действий, CSV и резервную копию базы.

**Система не принимает реальные платежи и не выпускает фискальные чеки.** Она хранит уже выданные документы, а скачиваемое описание заказа явно помечено как нефискальное. Не храните API-ключи в клиентском коде и не коммитьте базу, чеки, `.env` или резервные копии.

Полная инструкция установки на VPS h1cloud, подключения GitHub Pages, резервирования и ограничения: [docs/STORAGE.md](docs/STORAGE.md).

## Цены и изображения

Каталог и внутренний расчёт находятся в `catalog.js` и серверном модуле. Публичная витрина показывает рублёвые цены. Цены иллюстративные и требуют проверки перед продажами. Изменение каталога не меняет снимки уже сохранённых заказов.

В `assets/products/` — 10 WebP-иллюстраций; `assets/hero-world.webp` — авторская иллюстрация первого экрана. Они не являются официальными изображениями Hypixel. Дизайн описан в [DESIGN.md](DESIGN.md).

## Публикация

GitHub Pages: `main`, корень репозитория. Это только статическая витрина. Node-сервер и база размещаются отдельно на VPS. До установки сервера `api-config.js` оставлен пустым, чтобы не показывать несуществующее серверное сохранение. После установки в нём указывается только HTTPS-origin VPS, без секретов.

Независимый проект, не связан с Hypixel, Mojang или Microsoft.
