# PixelStore

Магазин рангов и цифровых товаров Hypixel. Адаптивная витрина с изображениями, корзиной и подтверждением MVP+ для MVP++. Один продавец: кабинет для ручного учёта покупок, расходов и документов; покупателям — история заказов с ценами на момент оформления.

## Запуск

Сервер: **Python 3.12 + Waitress + SQLite**, без Node.js, Docker и root-доступа.

```sh
pip install -r requirements.txt
python -m unittest discover -s test -v
python run.py
```

Локальная витрина: http://localhost:25011, кабинет: http://localhost:25011/admin. Для входа задайте случайный `ADMIN_TOKEN` минимум 32 символа через окружение или приватный `data/settings.json`. Пример структуры — `settings.example.json`. Файлы `.env` автоматически не загружаются.

**Для показанной панели h1cloud:** файл запуска `run.py`, библиотеки `waitress==3.0.2`, порт `25011`. SFTP — загрузка файлов, не SSH. Инструкция по архиву, HTTPS, резервным копиям и запуску: [docs/STORAGE.md](docs/STORAGE.md).

## Хранение

SQLite на постоянном диске хранит снимки заказов, отдельные статусы оплаты и выполнения, расходы, заметки, журнал действий и приватные PDF/JPEG/PNG/WebP. Продавец может явно открыть покупателю доступ к конкретному документу. Есть CSV и полная резервная копия с документами. Для плана с диском 1 ГБ установлен консервативный лимит базы 300 МБ с запасом для WAL и резервирования.

**Система не принимает реальные платежи и не выпускает фискальные чеки.** Отметки оплаты и возврата сохраняются после ручной сверки. Витрина создаёт демозаказы; ручная форма кабинета позволяет учитывать реальные покупки, принятые вне сайта. Скачиваемое описание заказа — нефискальное.

## Каталог и публикация

Источник каталога — `catalog.json`. После изменения выполните `python scripts/build_catalog.py` и опубликуйте также обновлённый `catalog.js`. Сервер использует тот же источник; уже созданные заказы сохраняют прежние цены. В интерфейсе цены в рублях; курс и формулы покупателям не показываются.

GitHub Pages публикует только статическую витрину. Пока HTTPS-сервер не установлен, `api-config.js` оставлен пустым: история локальная, продавцу заказы не отправляются. Сервер Python отдаёт свою витрину и кабинет; для подключения GitHub Pages потребуется его настоящий HTTPS-origin.

`assets/products/` содержит 10 иллюстраций товаров; `assets/hero-world.webp` — иллюстрация первого экрана. Дизайн: [DESIGN.md](DESIGN.md). Иллюстрации не являются официальными материалами Hypixel. Независимый проект, не связан с Hypixel, Mojang или Microsoft.
