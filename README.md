# PixelStore

Русскоязычная витрина рангов и донатов Hypixel: адаптивный каталог, сравнение рангов, корзина, оформление и скачивание демозаказа.

## Запуск

Сайт не требует сборки. Откройте `index.html` в браузере или запустите локальный сервер:

```sh
python3 -m http.server 8080
```

Затем откройте http://localhost:8080.

## Цены

Курс магазина: 1 USD = 100 RUB. Наценка на ранги — 5% с округлением до рубля. Каталог и формула находятся в `app.js`. Цены иллюстративные, актуальность нужно проверить перед запуском продаж.

## Статус оплаты

Магазин работает в демонстрационном режиме: деньги не списываются, ранг не выдаётся. Корзина и последний демозаказ сохраняются только в браузере посетителя. Сервер, платёжный провайдер, уведомления продавцу и управление исполнением заказов пока не подключены.

API-ключи платёжных сервисов должны храниться только на сервере, а не в публичных файлах сайта.

## Публикация

Для GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Независимый проект, не связан с Hypixel, Mojang или Microsoft.

## Изображения товаров

В `assets/products/` находятся 10 оптимизированных WebP-иллюстраций: отдельное изображение для каждого товара. Короны, монеты, сундук и бустеры — художественные иллюстрации, а не официальные изображения Hypixel. Нажатие на изображение открывает крупный просмотр с описанием и добавлением в корзину.
